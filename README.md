# UK Cost of Living Analysis

## 📌 Project Overview
This project analyses changes in the UK cost of living by comparing inflation trends with average earnings using official datasets from the Office for National Statistics (ONS).

The goal is to understand how rising prices have affected real wages and household affordability over time.

## 🎯 Objectives
- Analyse UK inflation trends over time
- Examine wage growth patterns
- Compare inflation vs earnings to assess real purchasing power
- Communicate insights through clear visualisations and an interactive dashboard

## 🗂️ Data Sources
- Office for National Statistics (ONS)
  - Consumer Price Index (CPI / CPIH)
  - Average Weekly Earnings

## 🧠 Methodology
1. Data collection from official sources
2. Data cleaning and preprocessing
3. Exploratory data analysis (EDA)
4. Feature engineering (real wages, growth rates)
5. Visualisation and insight generation
6. Interactive dashboard development using Streamlit

## 🛠️ Tech Stack
- Python
- pandas, numpy
- matplotlib / plotly
- Streamlit
